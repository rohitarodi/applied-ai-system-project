# Rule-based agent instead of an LLM, entire stack local-only

The RecommendationAgent, RatingPredictor, and TranscriptionTool all run without any cloud API key, so end users incur zero added cost and the system has no external dependency to fail or rate-limit. This means the RecommendationAgent's "plan/act/check/critique" reasoning is deterministic Python logic (scored against energy variance, artist repeats, and RatingPredictor output) rather than an LLM narrating its own reasoning in natural language — and RatingPredictor is a small local scikit-learn model, not a fine-tuned LLM. Considered running a local LLM via Ollama for more natural-sounding reasoning traces, but rejected it: it adds a runtime dependency (install, model download, RAM/CPU cost) and makes ReasoningTrace output non-deterministic, which works against reproducible grading evidence.
